## Reproducible evidence

The immutable artifact is `trade-evidence/tx-e164fc656bd996ce7be711a4753bb40f6088f18e8abe7dc60b530fa68d4a79cc.json`, with canonical SHA-256 `c7277da946c77d9eee6626bc3bf14ac4b54f4205c5c9886620a8b28052026963`. It includes the raw public transaction, receipt, block, network lookup statuses, decoded call/events, bounded trace and confidence assessment. `npm.cmd run verify` rehashes it and separately verifies the unchanged M0 snapshot chain and M1 execution chain. `node --experimental-strip-types scripts/capture-trade-evidence.ts <hash> <public-wallet>` reproduces a new read-only capture into an empty artifact path; it does not overwrite this file, sign or send a transaction. A new capture will have a different SHA-256 because `observedAt` and the later SDK market read are new observations.

The dashboard endpoint `POST /api/v1/trade-forensics` makes fresh read-only RPC/SDK requests and returns `VERIFIED`, `PARTIALLY_VERIFIED`, `UNKNOWN` or `MISMATCH` with separate network, receipt, decoded-event, wallet and position facts. It also returns the saved artifact hash when the inspected hash has an existing verified local artifact. `GET /forensics.js` serves the dedicated view. HTTP errors and non-JSON responses are shown safely.
