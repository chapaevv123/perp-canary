# Product roadmap

## Working today

Verified Hideki market discovery, real trusted quotes and indexed candles, wallet-scoped PostOnly planning, deterministic Guard, explicit wallet confirmation, open-tab alerts, paginated SDK order journal and one independently verified historical delegated BTC fill.

## Next milestones

- Add verified rolling 24h price and volume from complete indexer windows, then unlock volatility and activity filters with provenance.
- Reconcile per-order fills, execution prices and protocol fees with receipts/indexer pages; only then calculate realized PnL and win/loss for fully reconstructed lifecycles.
- Introduce authenticated tenant storage and opt-in background alerts with quotas, notification channels and account ownership proof.
- Complete public-domain security and performance smoke after approved deployment; improve market-scan cache and request budget using production telemetry.

## Long-term vision

AI Trading Copilot for explainable research; multi-DEX intelligence; cross-protocol execution analysis; advanced risk automation only after protocol-safe controls are independently verified; deeper trader analytics; and a scalable authenticated multi-user platform. These are planned concepts, not shipped capabilities. Autonomous trading is not part of the current product.
