# M8 product report — 2026-10-28

M8 extends the M7.4 trading terminal into an execution-intelligence workspace. The Radar uses the verified 21-PERP registry and trusted market snapshots. Alerts are configurable, persistent in the browser profile, and monitored only while the page is open. The Trade Journal reads paginated official SDK finished-order history and links the independently verified historical Canary fill. Position sizing adds absolute risk budget, tick checks, margin estimate and explicit estimated status. Terminal, Radar, Alerts, Journal and Planning share one navigation without altering the wallet-confirmed execution flow.

The M7.4 live history timeout came from scanning every block between a 2026 first order and the current head with three indexed `eth_getLogs` calls per 1,000-block chunk. That path grew without a bound. The endpoint now reads verified placement proof and current owner account, reports the historical gap as partial, and leaves the separately verified filled Canary order in Execution Replay. The new live Chromium history smoke passed. This is deliberately narrower than a complete old-order lifecycle index.
