An operator's top-level transaction has the operator as `msg.sender`; `placeOrderFor(owner, ...)` assigns the order and margin to the embedded owner. This grant does not authorize withdrawal or general fund transfer. The external MetaMask is **not currently granted** for this wallet. No grant or gas transfer was made here. For a direct EOA `placeOrder` call, the MetaMask EOA is both `msg.sender` and the MarginBank account; its balances cannot be borrowed from the app wallet.

## Implemented checkpoint

The top navigation displays the actual EIP-1193 account and opens a detail panel with checksummed address, provider, chain ID, separate STT/wallet USDso/free and withdrawable margin, copy, refresh and disconnect. Account/chain changes clear stale state. Funding reads use the connected address, never the embedded balance. Voucher eligibility is read-only; `claim()` preparation checks campaign wiring, eligibility, BTC allowlist, gas, pending nonce and simulation. Sending requires separate review, a fresh identical preflight and an explicit wallet confirmation. A successful receipt is further checked against on-chain voucher state. A live local API request at block 34705036 showed the MetaMask balance as zero and eligible; the claim prepare endpoint correctly returned **No Hideki STT for gas**. No signing or broadcasting occurred.
